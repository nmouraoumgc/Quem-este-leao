# Atribuição das fotografias de amostra

Os ficheiros nesta pasta têm nomes opacos (`sample_XX.jpg`) de propósito:
a identidade do jogador **não** vai no nome do ficheiro.

Operadores que adicionem fotografias extra **têm de ter direitos** (licença
reutilizável, autorização do titular, ou banco próprio). Guardar fonte e
créditos internamente (este manifesto / base de dados), nunca no nome público.
