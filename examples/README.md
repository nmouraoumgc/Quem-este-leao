# Exemplos gerados (pré-visualização local)

Ficheiros criados por `quem-e-este-leao generate` + `publish --dry-run`.

| Ficheiro | Público? | Conteúdo |
| --- | --- | --- |
| `quiz_<hex>.jpg` | sim (rede social) | Quadro 1080×1080, cara desfocada, EXIF limpo |
| `quiz_<hex>_caption.txt` | sim | Legenda do post **sem** o nome do jogador |
| `quiz_<hex>_ANSWERS_NAO_PUBLICAR.txt` | **NÃO** | Resposta correcta — só uso interno |

O nome do ficheiro é um identificador opaco. Não contém o nome do jogador.
